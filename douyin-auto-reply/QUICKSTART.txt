                    抖音AI自动回复助手 - 快速开始指南
================================================================================

您的电脑配置完全满足要求！

快速开始步骤：

1. 下载/复制整个 douyin-auto-reply 文件夹到您的电脑

2. 安装Python（如果还没有）
   - 访问 https://www.python.org/downloads/
   - 下载Python 3.8+（64位版本）
   - ⚠️  重要：安装时勾选 "Add Python to PATH"

3. 打开命令提示符（Win+R，输入cmd）

4. 进入项目文件夹，例如：
   d:
   cd douyin-auto-reply

5. 安装依赖：
   pip install -r requirements.txt

6. 运行程序：
   双击 "启动.bat"
   或者运行：python main.py

7. 开始使用！
