## 软件简介

抖音AI自动回复助手是一款专门为抖音运营者设计的智能回复工具，支持：
- 自动监控粉丝私信
- 自动监控作品评论
- 关键词精准回复
- AI智能自由回复
- 安全防封号设置
- 话术批量管理

## 系统要求

- 操作系统：Windows 10/11
- 内存：2GB及以上
- 硬盘：至少100MB可用空间
- 网络：需要联网（用于AI回复功能）

## 安装步骤

### 方式一：使用打包好的EXE文件（推荐）

1. 下载并解压软件压缩包
2. 双击运行 `抖音AI自动回复助手.exe`
3. 无需安装，直接使用

### 方式二：从源码运行

1. 确保已安装 Python 3.8+
2. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```
3. 运行程序：
   ```bash
   python main.py
   ```

### 方式三：自行打包

```bash
pip install pyinstaller
pyinstaller build.spec
```
打包好的EXE文件将在 `dist` 目录下

## 使用指南

### 1. 准备工作

#### 安装模拟器
- 下载并安装 MuMu模拟器 或其他安卓模拟器
- 在模拟器中安装抖音APP
- 登录您的抖音账号

#### 配置软件
1. 启动软件
2. 点击「系统设置」标签
3. 在「模拟器设置」中，确认窗口标题与您的模拟器窗口标题一致
4. 点击「查找模拟器」按钮，确认软件能找到模拟器窗口

### 2. 配置AI回复（可选）

如果需要使用AI智能回复功能：
1. 进入「系统设置」
2. 在「回复设置」中选择AI提供商（如OpenAI）
3. 填入您的API密钥
4. 选择AI模型（默认gpt-3.5-turbo）
5. 设置回复风格（如：友好、亲切、自然）
6. 点击「保存设置」

### 3. 配置关键词回复

1. 点击「关键词管理」标签
2. 输入关键词和对应的回复内容
3. 点击「添加关键词」
4. 也可以通过「批量导入」功能导入JSON格式的关键词列表

**关键词文件格式示例：**
```json
[
    {
        "keyword": "多少钱",
        "reply": "亲，这款产品现在有优惠活动呢！您可以私信我了解详情哦~"
    },
    {
        "keyword": "发货",
        "reply": "我们一般48小时内发货，发顺丰快递哦~"
    }
]
```

### 4. 启动监控

1. 确保模拟器已启动且抖音APP已打开
2. 点击主界面的「启动监控」按钮
3. 软件将开始自动监控私信和评论
4. 收到新消息时会自动回复

### 5. 安全设置建议

为避免账号被封，建议：
- 启用「随机延迟」，设置3-12秒的回复间隔
- 启用「敏感词过滤」
- 不要设置过于频繁的检查间隔（建议5秒以上）
- 避免使用过于营销化的回复话术

## 常见问题

### Q: 软件找不到模拟器窗口怎么办？
A: 请确认：
1. 模拟器已启动
2. 窗口标题设置正确
3. 尝试点击「查找模拟器」按钮

### Q: AI回复不工作？
A: 请检查：
1. API密钥是否正确填写
2. 网络连接是否正常
3. 账户余额是否充足

### Q: 会被封号吗？
A: 没有100%不封号的保证，但我们提供了多重安全措施：
- 随机回复延迟
- 敏感词过滤
- 建议配合人工回复使用

### Q: 支持哪些模拟器？
A: 理论上支持所有安卓模拟器，只需正确配置窗口标题即可。推荐使用MuMu模拟器。

### Q: 可以同时监控多个账号吗？
A: 当前版本暂不支持多账号监控，建议一个账号使用一个软件实例。
